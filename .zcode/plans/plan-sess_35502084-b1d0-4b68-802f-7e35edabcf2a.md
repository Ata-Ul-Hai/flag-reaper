## Architecture (research-verified, TrueForge-native)

- **reaper/** Python package = deterministic core, no LLM loop: Unleash inventory, ripgrep tracer, 6-rule ordered classifier, patch generator with branch-survival rule, JSONL audit log, PyGithub PR creator.
- **MCP tool server** (FastMCP, localhost streamable HTTP) exposing: `inventory_flags`, `trace_references`, `classify_flags`, `plan_removal`, `apply_and_test`, `open_pr`, `get_report`, `answer_unknown`. Every call appends to the audit log.
- **Reaper skill repo** (git-backed `SKILL.md` + scripts) pins the bounded procedure; imported into TrueForge.
- **Saved TrueForge agent**: model + skill + MCP server + `require_approval_for_tools: ["open_pr"]` (explicit tool name — unannotated tools bypass `@destructive`, a verified gotcha) + `ask_user_questions` for UNKNOWN flags + generative-UI evidence cards + `config.sandbox.enabled: true`.
- **Patch + test runs inside the Daytona sandbox** via skill script (satisfies "code run in a sandbox" judging criterion); local venv is fallback only.
- **Staleness signal (corrected):** `lastSeenAt` recency + last-hour metrics + simulated live traffic — not a 60-day historical window (OSS Unleash doesn't reliably expose it).
- **Thin backup** FastAPI `GET /report` + `GET /audit` as demo insurance; primary gate = TrueForge's native approval UI.
- LLM narration/PR prose is written by the TrueForge agent itself; dynamic-key detection stays deterministic (regex pre-pass + rules).
